# Debian 13 Rescue USB

An automated, lightweight rescue environment built on a minimal Debian 13 Live ISO. This system boots directly from a USB drive to provide a menu-driven interface for system diagnosis and data recovery.

## 📁 Repository Contents
* `.pdf` - Full project documentation, step-by-step creation guide, and system screenshots.
* `/scripts` - The individual automation scripts used to power the rescue menu interface.

## 🛠️ Menu Features Include:
* Disk failure diagnosis & partition repair
* Image backups and directory recovery
* Malware scanning & network connectivity checks
* Hardware information tools
